# HyperHDR Config for Skydimo (Linux)

Оптимизированная конфигурация для системы фоновой подсветки **Skydimo** при использовании программного обеспечения **HyperHDR** на ОС Linux (Ubuntu/Debian/Mint).

## 📊 Характеристики макета (LED Layout)
Конфигурация настроена для П-образной установки ленты (3 стороны монитора):
*   **Левая сторона:** 17 светодиодов (снизу вверх)
*   **Верхняя сторона:** 31 светодиод (слева направо)
*   **Правая сторона:** 17 светодиодов (сверху вниз)
*   **Всего:** 65 активных зон захвата.

## 🚀 Особенности этого конфига
*   **Минимальная задержка:** Настроен интераполятор "Infinite" с частотой 60 Гц для мгновенного отклика в играх.
*   **Правильные цвета:** Скорректирован баланс белого и насыщенность для устранения "кислотных" оттенков, характерных для Skydimo.
*   **Плавность:** Настроено демпфирование (Damping) и сглаживание для комфортного просмотра кино без резких вспышек.

## 🛠 Настройки оборудования
Если вы вводите данные вручную, используйте эти параметры:
*   **Тип контроллера:** `adalight`
*   **Порт:** `/dev/ttyUSB0` (чип CH340)
*   **Baudrate:** `115200`
*   **Тип захвата:** `Pipewire` или `X11` (Screen Capture)

## 📥 Как установить
1. Скопируйте содержимое файла `.json` из этого репозитория.
2. Откройте веб-интерфейс HyperHDR (обычно `localhost:8090`).
3. Перейдите в раздел **LED Hardware** -> **LED Layout**.
4. Найдите вкладку **Generated/Custom LED Layout**.
5. Вставьте скопированный текст в текстовое поле и нажмите **Save settings**.
